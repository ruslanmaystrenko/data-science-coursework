# Case studies

Thirteen short guided exercises, each built around one method. The data and
the outline came from the course. The work in each notebook is mine.

| Notebook | Method |
| --- | --- |
| `linear-regression.ipynb` | Linear regression |
| `logistic-regression.ipynb` | Logistic regression |
| `decision-tree.ipynb` | Decision trees |
| `random-forest.ipynb` | Random forests |
| `gradient-boosting.ipynb` | Gradient boosting |
| `knn-grid-search.ipynb` | Nearest neighbors with a parameter search |
| `clustering.ipynb` | Grouping customers with k means |
| `cosine-similarity.ipynb` | Measuring similarity by angle |
| `distance-measures.ipynb` | Euclidean and Manhattan distance |
| `frequentist-inference-part-1.ipynb` | Confidence intervals and sampling |
| `frequentist-inference-part-2.ipynb` | Hypothesis tests |
| `bayesian-optimization.ipynb` | Tuning a model with Bayesian optimization |
| `app-store-analysis.ipynb` | Comparing app ratings across two stores |
