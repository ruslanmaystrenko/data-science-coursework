# Data Science Coursework

Course projects and challenges from Springboard's data science program, kept in one place. My own projects are in their own repos.

| Folder | What it is | Question it answers |
| --- | --- | --- |
| [`big-mountain-resort`](big-mountain-resort) | Guided capstone | What should a ski resort charge for a lift ticket? |
| [`user-engagement`](user-engagement) | Take home challenge | Which users become regular users of a product? |
| [`ride-share-retention`](ride-share-retention) | Take home challenge | When is demand highest, and which riders stay? |
| [`case-studies`](case-studies) | Thirteen short case studies | One method each, from linear regression to gradient boosting |

## What each one covers

**Big Mountain Resort.** Data wrangling, exploration and a pricing model for a Montana ski resort, with a slide deck and written recommendations.

**User Engagement.** Defining an adopted user from login records and finding which account traits go with adoption.

**Ride Share Retention.** Login demand patterns by time of day and week, the design of an experiment on toll reimbursement, and a model of which riders stay active.

**Case Studies.** App store analysis, frequentist inference, linear and logistic regression, decision trees, random forest, gradient boosting, clustering, nearest neighbors with grid search, distance measures, cosine similarity and Bayesian optimization.

## Tools

Python, pandas, scikit learn, matplotlib and seaborn, in Jupyter notebooks.
